# Desktop 0.5.3 Official Core Sync Implementation Plan

English | [中文](2026-09-03-desktop-0.5.3-core-sync.zh.md)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Safely synchronize the released Desktop 0.5.2 Harness `0.1.1-rc.2` to official `0.1.2-alpha.5`, preserving Desktop extensions and legacy user data.

**Architecture:** Create a new branch from the exact Desktop baseline, merge the exact upstream tag while retaining auditable ancestry; first pin rc.2/alpha.3 upgrade fixtures, then resolve compilation, composition, and Desktop extension conflicts. The sync result provides only shared commits, without changing Desktop version or release metadata.

**Tech Stack:** Git, TypeScript, pnpm 11, Vitest, Electron, Playwright, JSONL/storage projection fixtures.
