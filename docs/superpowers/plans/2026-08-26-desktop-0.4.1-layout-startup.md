# Desktop 0.4.1 Layout and Startup Implementation Plan

English | [中文](2026-08-26-desktop-0.4.1-layout-startup.zh.md)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release one Mac Intel and Windows x64 Desktop 0.4.1 revision that keeps the character-slider footer stable with large model catalogs and reduces verified Desktop startup work.

**Architecture:** Preserve the existing popup placement and request semantics. Split the menu into fixed effort/footer regions around one scrolling model viewport; coalesce only duplicate model reads; add an opt-in verified cache around the Desktop module fallback; overlap independent window prerequisites; record fixed-name startup milestones.

**Tech Stack:** TypeScript, React, CSS Modules, Electron, Node.js filesystem APIs, Vitest, Testing Library, Playwright packaged smoke, electron-builder, GitHub Actions.
