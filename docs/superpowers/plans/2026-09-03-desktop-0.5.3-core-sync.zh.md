# Desktop 0.5.3 Official Core Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将已发布 Desktop 0.5.2 的 Harness `0.1.1-rc.2` 安全同步到官方 `0.1.2-alpha.5`，保留 Desktop 扩展及旧用户数据。

**Architecture:** 从精确 Desktop 基线创建新分支，先固定 rc.2/alpha.3 升级 fixture。由于 Desktop 产品史与官方仓库史没有 Git 共同祖先，先创建一个树不变的双父 provenance commit，只建立精确上游 tag 的可审计祖先关系；随后严格按路径归属清单导入官方文件，并在 alpha.5 seam 上重新接入最小 Desktop 能力。同步结果只提供共享 commit，不改 Desktop 版本或发布元数据。

**Tech Stack:** Git、TypeScript、pnpm 11、Vitest、Electron、Playwright、JSONL/storage projection fixtures。
