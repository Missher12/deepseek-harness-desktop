# Desktop 0.3.6 个性化、计费与记忆实施计划

[English](2026-08-24-desktop-0.3.6-personalization-billing-memory.md) | 中文

> **供 agentic worker 使用：** 必须使用子技能 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans，逐项执行本计划。步骤使用复选框（`- [ ]`）跟踪。

**目标：** 交付一个经过验证的 0.3.6 源码提交，使 macOS 和 Windows 应用都具备全局个性化、真实且实时的 DeepSeek 计费数据，以及默认开启并能在插件市场发现的内置记忆插件。

**架构：** 扩展已有 DeepSeek 余额桥接和统计栏所有者，不新增第二套计费服务。为 loopback API 增加有限的个性化方法，并新增专用设置客户端包，只编辑规范全局指令文件中的标记区块。修复并发布独立记忆 Bundle，再让 Desktop 使用完全相同的发行物作为回退副本，同时保留配置目录内更新版本的优先级。

**技术栈：** TypeScript、React 18、Cordis、Zod、Vitest、pnpm、Electron Builder、GitHub Actions 与 Releases。
