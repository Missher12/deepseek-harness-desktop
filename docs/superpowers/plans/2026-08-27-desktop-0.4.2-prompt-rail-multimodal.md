# Desktop 0.4.2 Prompt Rail and Multimodal Implementation Plan

English | [中文](2026-08-27-desktop-0.4.2-prompt-rail-multimodal.zh.md)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the earlier Desktop 0.4.2 with a 0.4.1-based release that adds only a Codex-style prompt navigation rail and reliable custom-model image capability controls.

**Architecture:** Project a lightweight all-history prompt index on the Host tail response, keep it in the React-free Session object, and render a bounded left-gutter rail that only pages and scrolls. Extend existing model discovery metadata and the open `pi-ai` model draft with explicit modalities; the resolved model profile remains the attachment-admission authority.

**Tech Stack:** TypeScript, React, CSS Modules, Cordis, Zod, Vitest, Testing Library, Playwright replay snapshots, Electron, electron-builder, GitHub Actions.
