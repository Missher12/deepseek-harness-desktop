# Desktop 0.5.4 核心、启动与交付实施计划

[English](2026-09-04-desktop-0.5.4-core-startup-delivery.md) | 中文

> **必用技能：** `superpowers:executing-plans`、`superpowers:test-driven-development` 与 `superpowers:verification-before-completion`。

**目标：** 同步精确官方 Harness `0.1.2-rc.1`，保留 Desktop 扩展与用户状态，只优化实测启动瓶颈，并从一个唯一最终 SHA 发布、安装双平台 `0.5.4`。

**架构：** 保留祖先关系合入精确上游提交 `a66e4702047846cdaa10c66c9d3df3951f5ea70d`。官方 alpha.5 到 rc.1 的 tree 变化仅为 252 个 package 版本行；任何额外 merge 差异都视为冲突并审计。启动 readiness 不得提前。继续使用现有 build-once quick/full workflow 作为平台门禁。

### 任务 1：同步精确官方 rc.1

- [ ] 核对 alpha.5 为祖先，记录官方 252 个单行版本差异，并写 manifest RED，要求 root/core package 对齐 rc.1。
- [ ] 保留祖先关系合入 `a66e4702047846cdaa10c66c9d3df3951f5ea70d`。拒绝任何意外源码、lockfile、snapshot 或生成文件差异。
- [ ] 运行 host/client TypeScript、profile boot、Desktop manifest、stage、BrowserSkill、记忆/进化与升级态测试。
- [ ] 提交 merge/兼容结果，但不改 Desktop 版本。

### 任务 2：测量启动关键路径

**文件：** `packages/boot/app-boot/src/index.ts`、`apps/cli/src/profile-boot.ts`、`apps/desktop/src/startup-timeline.ts`、benchmark parser/tests，以及唯一实测第一方瓶颈。

- [ ] 增加固定、不含路径的 Loader 构建、root include、第一方解析/导入、root activation、settle 与 audit 细分阶段；普通 CLI 输出不变。
- [ ] 在同一机器/runner 对公开 0.5.3 与当前候选各采集 10 次冷启动和 10 次热启动。
- [ ] 为最大的重复或非关键 eager 工作写 RED，只实现一种有界优化：单次启动 single-flight/去重、安全懒加载或内容键可重建缓存。
- [ ] 只有一项 median 至少改善 15%、另一项 median 退化不超过 5%、两项 P95 退化不超过 10%，并且生命周期/readiness/数据保留全绿时才保留。否则撤销产品捷径，只保留诊断。

### 任务 3：冻结唯一发布 SHA

- [ ] 共享代码和测试全绿后才把 Desktop 版本与发布元数据改为 0.5.4/core rc.1。双语 README/发布上下文和校验值只能来自实际产物。
- [ ] 合入平台 smoke 适配，不重写共享文件。跑本地门禁并保持 clean。
- [ ] 推送唯一 integration SHA，把完整 SHA 发给两端。任何源码变化都会使此前 run/artifact 全部失效。

### 任务 4：Mac 与 Windows 原生验收

- [ ] Mac Intel full：DMG build/mount、x86_64、标题栏排除区、100%/150% UI、左侧刻度、Workbench/插件、冷/热各 10 次、启动/关闭/Dock/Quit/进程树、旧状态与用户数据保留。
- [ ] Windows x64 full：Setup/NSIS、快捷方式/图标、100%/150% UI、左侧刻度、Workbench/插件、冷/热各 10 次、安装/启动/关闭/tray/卸载/进程树、旧状态与用户数据保留。
- [ ] 两端回报产物 basename、bytes、SHA-256、benchmark median/P95、run/job id 与有界视觉证据。两端都不得 tag 或发布。

### 任务 5：发布并安装

- [ ] 只有同一 SHA 的双平台都通过后，才能合并 main、push、创建 `desktop-v0.5.4`、运行 release workflow，并匿名重新下载核对公开资产 SHA-256。
- [ ] 在本机安装已验证 Intel DMG，正常启动，并在真实 profile 上核对标题栏、左侧刻度、Workbench、`@/+`、BrowserSkill 与 Open Design companion 状态，且不改写用户数据。
- [ ] 如实报告改善与未改善项。最终同 runner 数据未过门槛时不得宣称启动更快。
