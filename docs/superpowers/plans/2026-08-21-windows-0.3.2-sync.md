# Windows Desktop 0.3.2 Synchronization Implementation Plan

English | [中文](2026-08-21-windows-0.3.2-sync.zh.md)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build, verify, and publish a Windows x64 Setup from the same Desktop 0.3.2 source as the current Intel macOS release, without changing any Mac release asset.

**Architecture:** Keep one shared Desktop source and adapt only operating-system boundaries. Derive every Windows artifact path from `apps/desktop/package.json`, launch a native shell through a typed workbench shell command, make the installed-app smoke exercise the shared 0.3.2 UI on both platforms, and keep public release upload as a separate exact-asset operation after native Windows acceptance.

**Tech Stack:** Electron, TypeScript, React, Vitest, pnpm, GitHub Actions, PowerShell, electron-builder/NSIS.

---

## File map

- `.github/workflows/windows-desktop.yml`: derive Windows artifact names from the Desktop package version and reuse the resolved path through build, smoke, checksum, and upload.
- `scripts/ci-workflow.spec.ts`: lock the dynamic-version workflow contract and reject stale hard-coded release names.
- `packages/extensions/desktop-workbench/src/terminal.ts`: select a native PowerShell command on Windows or a login shell on POSIX, then pass the complete typed command to the terminal process owner.
- `packages/extensions/desktop-workbench/tests/terminal.host.spec.ts`: cover Windows and POSIX shell selection and the spawned argv.
- `apps/desktop/tests/packaged-smoke.ts`: exercise workbench and reasoning on installed Windows and use a platform-native terminal command.
- `apps/desktop/tests/packaged-smoke-helpers.spec.ts`: cover the Windows and POSIX terminal smoke commands.
- `apps/desktop/README.md` and `apps/desktop/README.zh.md`: document the version-derived Windows build and current verification commands.
- `packages/extensions/desktop-workbench/README.md` and `.zh.md`: document the Windows workbench boundary.
- `.agents/notes/implemented/feature/2026-08-14-cross-platform-desktop-installers.md` and `.zh.md`: record the durable Windows release and native-shell decisions.
- `PROJECT_CONTEXT.md`: record only final run, source commit, public byte size, and SHA-256 evidence after publication.
