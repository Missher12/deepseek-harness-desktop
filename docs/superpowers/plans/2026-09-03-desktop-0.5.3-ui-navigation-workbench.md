# Desktop 0.5.3 Navigation and Workbench Implementation Plan

English | [中文](2026-09-03-desktop-0.5.3-ui-navigation-workbench.zh.md)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans and superpowers:test-driven-development. Complete each checkbox in order and return evidence after every task.

**Goal:** Implement piano-key-style session navigation based on official alpha.5's complete Turn outline, and transform the existing Desktop Workbench into a clear, fixed, on-demand-loaded single right sidebar.

**Architecture:** Official `TurnNavigator` is the sole session navigator; modify only first-party data-to-visual chains without injecting external DOM selectors. The existing `desktop-workbench` remains the single right sidebar, organizing Review, Terminal, Browser, Files through a registry and dynamic imports; the BrowserSkill page reserves only type-constrained extension entry points, not implementing runtime in this phase.

**Tech Stack:** React, TypeScript, CSS Modules, Cordis Client slots, Vitest, Testing Library, Playwright, Electron.

**Prerequisite input:** The complete alpha.1 core-sync SHA dispatched by the commander. Executors must detached-verify that SHA before creating a dedicated branch; do not guess baselines from floating branch names.
