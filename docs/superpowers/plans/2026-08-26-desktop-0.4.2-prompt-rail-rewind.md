# Desktop 0.4.2 Prompt Rail and Safe Rewind Implementation Plan

English | [中文](2026-08-26-desktop-0.4.2-prompt-rail-rewind.zh.md)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a Codex-style prompt rail and source-preserving edit/continue workflow as Desktop 0.4.2, with Mac Intel implemented and accepted first.

**Architecture:** The Host extends `session.fork` with an optional `before-turn` cut and folds lightweight prompt anchors into the existing tail-history response. Client Runtime keeps the anchor projection and loads old pages only when selected. The conversation UI overlays a prompt rail and turns editing into a new lineage child with an unsent draft; source history is never truncated.

**Tech Stack:** TypeScript, Cordis, Zod RPC schemas, React, CSS Modules, Vitest, Web snapshot tests, Electron macOS x64 packaging.
