# Desktop 0.5.2 界面与会话权限实施计划

[English](2026-09-02-desktop-0.5.2-interface.md) | 中文

> **面向 agent 执行者：** 必须使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐项实施本计划。步骤使用复选框（`- [ ]`）跟踪。

**目标：** 在当前数据流上恢复 v0.4.11 PromptRail，整理 ChatGPT 风格左侧栏，把现有工作台改成固定右栏内的纵向导航，并为当前 Session 提供可撤销的“不再询问”。

**架构：** 不增加第二套会话、工作台或权限系统。PromptRail 只消费 `PromptAnchor`；侧栏只改现有行的展示；工作台继续由 Layout utility pane 承载；会话免询问复用 `/permission danger-full-access` 和 Session 事件。

**技术栈：** TypeScript、React、CSS Modules、Cordis Client Slots、Vitest、Testing Library、Playwright、Electron packaged smoke。

**基线与所有者：** 基线由总指挥提供的完整 SHA 决定；Mac 执行任务是本计划共享实现的唯一所有者。Windows 任务只能在收到共享提交后做 Windows 视觉和原生验收。
