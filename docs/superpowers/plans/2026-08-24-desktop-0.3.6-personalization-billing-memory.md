# Desktop 0.3.6 Personalization, Billing, and Memory Implementation Plan

English | [中文](2026-08-24-desktop-0.3.6-personalization-billing-memory.zh.md)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship one verified 0.3.6 source commit whose macOS and Windows applications provide global personalization, truthful live DeepSeek billing facts, and a default-on built-in memory plugin that is also discoverable in the plugin marketplace.

**Architecture:** Extend the existing DeepSeek balance bridge and statistics owner instead of adding a second billing service. Add bounded personalization methods to the loopback API and a dedicated Settings Client package that edits only a marked block in the canonical global instruction file. Fix and release the standalone memory bundle, then consume that exact artifact as the Desktop fallback while preserving profile-local update precedence.

**Tech Stack:** TypeScript, React 18, Cordis, Zod, Vitest, pnpm, Electron Builder, GitHub Actions and Releases.
