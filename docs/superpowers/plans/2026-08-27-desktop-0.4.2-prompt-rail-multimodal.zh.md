# Desktop 0.4.2 发言刻度与多模态实现计划

[English](2026-08-27-desktop-0.4.2-prompt-rail-multimodal.md) | 中文

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 替换较早发布的 Desktop 0.4.2，以 0.4.1 为基线，只加入 Codex 风格的发言导航刻度和可靠的自定义模型图片能力设置。

**架构：** Host 在历史尾页投影轻量全历史发言索引，React-free Session 对象保存索引，左侧边栏只执行按需分页和滚动。模型发现链增加可选输入模态，自定义 `pi-ai` 模型继续使用开放草稿结构；解析后的模型能力仍是图片附件准入的权威来源。

**技术栈：** TypeScript、React、CSS Modules、Cordis、Zod、Vitest、Testing Library、Playwright 回放快照、Electron、electron-builder、GitHub Actions。
