# Windows Desktop 0.3.2 同步实施计划

[English](2026-08-21-windows-0.3.2-sync.md) | 中文

> **面向智能体执行者：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans` 子技能逐项执行本计划。步骤使用复选框（`- [ ]`）跟踪。

**目标：** 使用当前 Intel macOS Release 相同的 Desktop 0.3.2 源码构建、验收并发布 Windows x64 Setup，同时不改动任何 Mac Release 资产。

**架构：** 保持一份共享 Desktop 源码，只适配操作系统边界。所有 Windows 产物路径从 `apps/desktop/package.json` 派生；通过有类型约束的工作台 shell 命令启动原生终端；让已安装应用 smoke 在两个平台验收共享 0.3.2 界面；在 Windows 原生验收完成后，通过独立的精确资产操作发布到公开 Release。

**技术栈：** Electron、TypeScript、React、Vitest、pnpm、GitHub Actions、PowerShell、electron-builder/NSIS。

---

## 文件图

- `.github/workflows/windows-desktop.yml`：从 Desktop 包版本派生 Windows 产物名，并在构建、smoke、校验和与上传中复用解析后的路径。
- `scripts/ci-workflow.spec.ts`：固定动态版本工作流契约，拒绝陈旧的硬编码 Release 名称。
- `packages/extensions/desktop-workbench/src/terminal.ts`：Windows 选择原生 PowerShell、POSIX 选择登录 shell，并把完整、有类型的命令传给终端进程所有者。
- `packages/extensions/desktop-workbench/tests/terminal.host.spec.ts`：覆盖 Windows/POSIX shell 选择和最终启动参数。
- `apps/desktop/tests/packaged-smoke.ts`：在已安装 Windows 应用中验收工作台与推理档位，并使用平台原生终端命令。
- `apps/desktop/tests/packaged-smoke-helpers.spec.ts`：覆盖 Windows 和 POSIX 的终端 smoke 命令。
- `apps/desktop/README.md` 与 `apps/desktop/README.zh.md`：记录由版本派生的 Windows 构建方式和当前验收命令。
- `packages/extensions/desktop-workbench/README.md` 与 `.zh.md`：记录 Windows 工作台边界。
- `.agents/notes/implemented/feature/2026-08-14-cross-platform-desktop-installers.md` 与 `.zh.md`：记录长期有效的 Windows 发布与原生 shell 决策。
- `PROJECT_CONTEXT.md`：只在发布后记录最终 run、源码提交、公开字节大小和 SHA-256 证据。
