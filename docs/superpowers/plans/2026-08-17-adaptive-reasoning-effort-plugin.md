# Adaptive Reasoning-Effort Plugin Implementation Plan

English | [中文](2026-08-17-adaptive-reasoning-effort-plugin.zh.md)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a removable Harness-native model selector that preserves HanaAyane's Canvas effort effect, defaults its popup below the composer, and stores the optional character preference in the active profile.

**Architecture:** Add one dual-face workspace package at `packages/extensions/reasoning-effort`: its Host half owns a boolean preference and exact loopback routes, while its Client half occupies `conversation.input.model` at priority `-100` and reads model and effort values only from `ModelDirectory`. Desktop mounts the package through its existing patch and staging pipeline; disabling the row releases the slot to the native priority-`0` selector.

**Tech Stack:** TypeScript, React 18, Cordis, Harness Client slots and ModelDirectory, Canvas 2D, `react-dom` portals, Vitest, Testing Library, Electron staging.
