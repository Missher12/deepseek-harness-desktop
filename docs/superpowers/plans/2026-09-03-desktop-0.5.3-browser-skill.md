# Desktop 0.5.3 BrowserSkill Implementation Plan

English | [中文](2026-09-03-desktop-0.5.3-browser-skill.zh.md)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans, superpowers:test-driven-development, and superpowers:systematic-debugging for any native failure.

**Goal:** Integrate Tencent BrowserSkill as an auditable, dual-platform, dormant-by-default built-in capability of Desktop; the model controls the plugin-owned Agent Window exclusively through structured `browser_*` tools.

**Architecture:** Use the published npm plugin `@wxg-prc-cpg/browser-skill-dsh-plugin@0.1.2`, not directly packaging the unreleased 0.2.0 from GitHub `main`. Use the Intel macOS / Windows x64 CLI from GitHub `cli-v0.1.11`, downloading and verifying digests at build time; the final artifact ships only the current platform's binary. The plugin remains `lazyTools:true`; a Desktop patch removes its unnecessary startup `bsk --version` subprocess and disables the floating overlay; state and connection guidance enter the single Workbench tab.

**Pinned supply chain:**

- npm plugin: `0.1.2`, integrity `sha512-k6BeAN0SpuaBj0M62wQhcKjCN7Fk6K6NTzGc/5c6LnOW2EvfQxdBssdnKhn7lLyTN3qHktCTpTeJsHdQUcnnTg==`
- Mac archive: `bsk-v0.1.11-x86_64-apple-darwin.tar.gz`, SHA-256 `f1e0749fc2fac11f81d931862efa331bb9fcba30d1a5cce83b2a10626bb02bf6`
- Windows archive: `bsk-v0.1.11-x86_64-pc-windows-msvc.zip`, SHA-256 `041785147342a704fd576470e63307880043a15ad52e0553f12e6dcf360ccf74`
- upstream source audited at `945bf1523dc969ba6c359368c56c01047ccdeeea`

**Prerequisite input:** The complete alpha.2 UI SHA dispatched by the commander. The Windows task is the sole owner of shared adaptation; the Mac task consumes and adds Intel assets/native acceptance only after that commit completes.
