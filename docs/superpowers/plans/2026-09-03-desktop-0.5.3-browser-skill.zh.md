# Desktop 0.5.3 BrowserSkill Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans, superpowers:test-driven-development, and superpowers:systematic-debugging for any native failure.

**Goal:** 把 Tencent BrowserSkill 作为可审计、双平台、默认休眠的 Desktop 内置能力；模型只通过结构化 `browser_*` 工具控制插件拥有的 Agent Window，并在能力真实挂载时进入 composer 的 `@` 插件目录。

**Architecture:** 使用已公开 npm 插件 `@wxg-prc-cpg/browser-skill-dsh-plugin@0.1.2`，不直接打包 GitHub `main` 的未发布 0.2.0。使用 GitHub `cli-v0.1.11` 的 Intel macOS/Windows x64 CLI，构建时下载并校验摘要，成品只带当前平台。插件保持 `lazyTools:true`，Desktop 补丁移除其无必要的启动期 `bsk --version` 子进程并关闭浮动 overlay；状态与连接引导进入唯一 Workbench tab。

**Pinned supply chain:**

- npm plugin: `0.1.2`, integrity `sha512-k6BeAN0SpuaBj0M62wQhcKjCN7Fk6K6NTzGc/5c6LnOW2EvfQxdBssdnKhn7lLyTN3qHktCTpTeJsHdQUcnnTg==`
- Mac archive: `bsk-v0.1.11-x86_64-apple-darwin.tar.gz`, SHA-256 `f1e0749fc2fac11f81d931862efa331bb9fcba30d1a5cce83b2a10626bb02bf6`
- Windows archive: `bsk-v0.1.11-x86_64-pc-windows-msvc.zip`, SHA-256 `041785147342a704fd576470e63307880043a15ad52e0553f12e6dcf360ccf74`
- npm 插件源码审计点：`945bf1523dc969ba6c359368c56c01047ccdeeea`
- CLI 发布坐标：`cli-v0.1.11`；其 provenance 由该 tag、平台归档名与上列归档 SHA-256 共同记录，不把插件源码 SHA 误写成 CLI tag commit

**前置输入：** 总指挥下发的完整 alpha.2 UI SHA。Windows 任务是共享适配唯一所有者；Mac 任务只在该提交完成后消费并增加 Intel 资产/原生验收。

expect(desktopConfig).toMatchObject({ lazyTools: true, observationEnabled: false })
```

- [ ] **Step 1: 写环境和零进程 RED**

Harness child 的 `PATH` 只在 Desktop 进程内前置精确 packaged CLI 目录，保留原 PATH；路径必须为 app resources 内的物理文件。启动到 `desktop-running` 前 mock spawn 只能看到 Harness child，不能看到 `bsk` 或浏览器。

- [ ] **Step 2: 写工具面与 `@` 可发现性 RED**

组合只有一个 BrowserSkill row；结构化工具只允许 `browser_session/page/inspect/interact/tabs/assist`，不允许 `evaluate`、`record` 或任意 CDP。适配器挂载时在当前 Session 的既有 skill registry 发布唯一 `browser-skill` 用户可调用条目，使 UI 的通用 `@skill-mention` source 自动发现它；禁用/卸载适配器后条目必须消失。skill 正文只指导模型使用上述结构化工具，不授予新权限。未调用 skill 前正文不进入 prompt，冷启动也不探测 CLI/扩展。

- [ ] **Step 3: 实现最小挂载**

  config:
    bskPath: bsk
    lazyTools: true
    observationEnabled: false
```

不得自动安装扩展、自动借用标签页或修改浏览器 profile。
