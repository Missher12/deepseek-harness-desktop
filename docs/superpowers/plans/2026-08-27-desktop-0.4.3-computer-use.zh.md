# Desktop 0.4.3 Computer Use 实施计划

[English](2026-08-27-desktop-0.4.3-computer-use.md) | 中文

> **面向 agentic worker：** 必须使用子 skill：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans，逐项任务实施本计划。各步骤使用复选框（<code>- [ ]</code>）语法跟踪。

**目标：** 基于同一份源代码，为 Intel macOS 和 Windows x64 发布 Desktop 0.4.3，包含用户批准的 Codex 风格发言刻度、对内置浏览器的结构化 agent 控制，以及可见、可撤销的多应用 Computer Use。

**架构：** 模型工具保留在 Harness 内，特权执行则置于 Electron 主进程和一个按需启动的原生 helper 中。两个带类型的服务 seam（<code>browserControl</code> 和 <code>computerControl</code>）通过严格的共享协议跨越唯一的父子 Node IPC 通道；Electron 拥有租约和策略，原生 helper 则镜像并重新校验它们。浏览器操作使用进程内 CDP wrapper 和绑定版本的不透明 ref；原生操作优先使用 AX/UIA ref，并且仅为支持视觉的模型使用坐标。

**技术栈：** TypeScript、React、CSS Modules、Cordis、Zod/Schemastery、Electron WebContentsView/CDP、Node 子进程 IPC、Rust、macOS AXUIElement/ScreenCaptureKit/CGEvent、Windows UI Automation/Windows Graphics Capture/SendInput、Vitest、Playwright 快照、electron-builder、GitHub Actions。

---

任务 1–2 是独立的发言刻度切片。任务 3–8 交付完整的浏览器控制切片。任务 9–13 按观察 → 停止/清理 → 输入的顺序加入 Computer Use。只有前面的门禁全部为绿色后，任务 14 才会修改版本和发布元数据。
