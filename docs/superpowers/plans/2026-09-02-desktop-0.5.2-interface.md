# Desktop 0.5.2 Interface and Session Permission Implementation Plan

English | [中文](2026-09-02-desktop-0.5.2-interface.zh.md)

> **For implementing agents:** You must use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task by task. Track progress with the `- [ ]` checkboxes.

**Goal:** Restore the v0.4.11 PromptRail on current data flow, refine the existing sidebar with ChatGPT-like rhythm, arrange the existing Workbench as vertical navigation inside its fixed right pane, and add a reversible current-Session no-more-prompts action.

**Architecture:** Add no second session, Workbench, or permission system. PromptRail only consumes `PromptAnchor`; sidebar work remains presentation-only; Layout's utility pane continues to own Workbench; the no-more-prompts action reuses `/permission danger-full-access` and Session events.

**Stack:** TypeScript, React, CSS Modules, Cordis Client Slots, Vitest, Testing Library, Playwright, and Electron packaged smoke.

**Baseline and owner:** The commander's full SHA is the baseline. The Mac execution task is the sole owner of shared implementation in this plan. The Windows task may perform Windows visual and native acceptance only after receiving the shared commit.
