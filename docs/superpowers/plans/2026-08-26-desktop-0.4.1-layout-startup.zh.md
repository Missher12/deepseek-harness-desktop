# Desktop 0.4.1 布局与启动优化实施计划

[English](2026-08-26-desktop-0.4.1-layout-startup.md) | 中文

> **面向 agent 执行者：** 必须使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐项实施本计划。步骤使用复选框（`- [ ]`）跟踪。

**目标：** 使用同一提交发布 Mac Intel 与 Windows x64 Desktop 0.4.1，在大量模型时保持角色滑块底栏稳定，并减少经过验证的 Desktop 启动工作。

**架构：** 保留现有弹窗定位与请求语义。把菜单拆成固定推理区、独立滚动模型区和固定底栏；只合并重复的模型读取；为 Desktop 模块回退增加可选且逐项校验的缓存；并行处理互不依赖的窗口前置工作；记录固定名称的启动里程碑。

**技术栈：** TypeScript、React、CSS Modules、Electron、Node.js 文件系统 API、Vitest、Testing Library、Playwright packaged smoke、electron-builder、GitHub Actions。
