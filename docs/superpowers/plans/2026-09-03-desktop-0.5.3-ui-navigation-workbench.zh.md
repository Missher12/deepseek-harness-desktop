# Desktop 0.5.3 Navigation and Workbench Implementation Plan

[English](2026-09-03-desktop-0.5.3-ui-navigation-workbench.md) | 中文

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans and superpowers:test-driven-development. Complete each checkbox in order and return evidence after every task.

**Goal:** 基于官方 alpha.5 的完整 Turn outline 实现钢琴键式会话导航，并把现有 Desktop Workbench 改成清晰、固定、按需加载的单一右栏。

**Architecture:** 官方 `TurnNavigator` 是唯一会话导航；只改第一方数据到视觉链，不注入外部 DOM 选择器。现有 `desktop-workbench` 保持唯一右栏，通过注册表和动态 import 组织 Review、Terminal、Browser、Files；BrowserSkill 页只预留受类型约束的扩展入口，不在本阶段实现运行时。

**Tech Stack:** React、TypeScript、CSS Modules、Cordis Client slots、Vitest、Testing Library、Playwright、Electron。

**前置输入：** 总指挥下发的完整 alpha.1 core-sync SHA。执行者必须 detached 核对该 SHA 后再创建专属分支；不得从浮动分支名猜测基线。
