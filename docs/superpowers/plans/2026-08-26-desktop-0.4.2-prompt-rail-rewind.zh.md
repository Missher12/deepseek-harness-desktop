# Desktop 0.4.2 发言刻度与安全回退实施计划

[English](2026-08-26-desktop-0.4.2-prompt-rail-rewind.md) | 中文

> **给智能体执行者：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans` 逐项执行本计划。步骤使用复选框（`- [ ]`）跟踪。

**目标：** 以 Desktop 0.4.2 交付 Codex 风格发言刻度和保留源会话的编辑／继续流程，先完成并验收 Mac Intel。

**架构：** Host 为 `session.fork` 增加可选 `before-turn` 切点，并把轻量发言锚点折叠进现有尾页历史响应。Client Runtime 保存锚点投影，只在用户选择旧锚点时加载旧页。会话 UI 覆盖显示刻度栏，并把编辑转换为带谱系的新子会话和未发送草稿；绝不裁剪源历史。

**技术栈：** TypeScript、Cordis、Zod RPC schema、React、CSS Modules、Vitest、Web 快照测试、Electron macOS x64 打包。
