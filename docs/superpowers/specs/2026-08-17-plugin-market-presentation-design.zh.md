# 插件市场展示插件设计

[English](2026-08-17-plugin-market-presentation-design.md) | 中文

**日期：** 2026-08-17

**状态：** 待实现

**目标：** `dshmarket@1.10.1` 的独立替代构建；本轮只交付 Intel macOS Desktop

## 目标

插件市场使用适合 800 像素设置窗口和约 564 像素内容区的紧凑商店列表。安装、更新、启用、停用、删除、诊断、备份、失败回滚和来源警告继续由现有 `dshmarket` Host 实现负责。

本设计不通过运行时 CSS、DOM 查询或哈希类名覆盖现有市场。`dshmarket@1.10.1` 没有稳定的外观 API 或子槽位，另一个插件也不能用相同 `market` id 包装其 `settings.section`。因此成品使用一个可追溯的 `dshmarket` 替代构建，只修改 Client 展示代码，并保持一个市场 Loader 和一个设置页注册。

## 包与升级责任

- 替代构建锁定 `dshmarket@1.10.1` npm tarball integrity `sha512-8AWM8RT2tttJsozTBm6mAfI+cNpCIbeBdP9IoydJdHlH/+x72aNqmv3AWdbNfKDDwkkqM2Ce/XRDhha9HG0Q5Q==` 与上游提交 `6970a6f801108c04234eb953ff0f707feffa621a`，并保留其许可证、第三方声明、包名兼容要求和上游链接。
- Desktop composition 只把市场插件来源切换到替代构建；Harness 核心包、Electron preload、`desktopProfiles` 和 `desktopPnpm` 服务不改变。
- Host 路由、请求字段、目录校验、包操作锁、回滚、热挂载判断和安全确认不接受展示层改动。
- 每次跟随上游版本时重新应用独立 Client 补丁并运行 Host 行为等价测试；无法干净应用时继续使用已验证版本，不在启动时下载或注入补丁。
- Desktop 保留 `dshmarket` 预期的依赖键、Loader id、设置页 id 和活动市场自我保护；替代版与原版不能同时挂载。锁定的 Host 补丁在目标包为 `dshmarket` 时拒绝更新、停用和删除，其他所有包操作保持上游行为。

## 信息架构

设置导航保留一个“插件市场”入口。内容区顶部依次放置标题、刷新操作、`发现 / 已安装 / 更新 / 操作记录` 分段标签、搜索框、筛选入口和单行可横向滚动的高频分类。

插件目录使用列表，不使用两列卡片网格。每行包含 40 像素图标、名称、作者与版本、两行内描述、少量标签、状态和一个主操作。安装、更新或重新启用是唯一主按钮；源码、详情、复制包名和低频操作进入更多菜单。

已安装状态、可更新数量、目录来源与成员状态和失败状态使用文字与图标共同表达，不依赖颜色。目录成员状态只说明条目来自哪个已配置的 live、cache 或 snapshot 目录，不代表包签名、已验证发布者身份或安全背书。搜索结果、空状态、离线快照、加载失败和操作进行中占用稳定位置，不让工具栏或列表跳动。

## 视觉与交互

- 使用 Harness 的 `--dsw-alias-*` 主题变量和官方 UI primitives，不建立独立配色系统。
- 工具栏在目录滚动时保持可见；分类横向滚动，低频分类由筛选面板承载。
- 分段标签使用 `tablist`、`tab` 和 `aria-selected`；搜索、筛选、更多菜单和重复操作按钮包含插件名的可访问名称。
- 键盘顺序遵循标题操作、标签、搜索、筛选、分类、列表项目和主操作；焦点不进入不可见标签页或关闭的菜单。
- `prefers-reduced-motion` 关闭装饰动画；200% 缩放和窄窗口使用单列列表且不产生横向页面滚动。

## 安全与失败

展示插件不新增自由输入的包规格、命令、路径、注册表或可执行文件字段。目录成员和命令目标继续由 Host 重新解析，pnpm 未批准构建脚本继续默认阻止。

安装确认继续展示来源、版本、第三方代码警告和构建脚本状态。操作失败保留现有有界日志、取消、回滚和重试语义。插件界面不得读取或显示凭据、会话正文、工作区内容或 Electron 用户数据。

替代构建不与原版市场同时挂载。重复 Loader、Host 路由或设置页 id 可能在市场 Client 渲染前抛错，因此 composition 预检与临时 staged-profile 启动测试会在启用前拒绝这些冲突；若两层保护均被绕过，只有 Harness 启动诊断能够可靠显示错误。已经成功挂载的市场可以显示后续 Host 与 Client 版本不匹配或缺少 Desktop 服务，并拒绝变更包状态；Harness 的会话和模型功能继续可用。

## 验证与验收

- 上游市场业务测试继续覆盖搜索、筛选、分页、安装、更新、启用、停用、删除、诊断、备份、恢复、确认和失败回滚。
- 新组件测试覆盖列表信息层级、单一主操作、更多菜单、状态文本、空状态、离线快照、加载失败和操作锁。
- 浏览器验收使用真实 800 像素设置窗口和约 564 像素内容区，覆盖浅色、深色、英文长标签、320 像素重排、200% 缩放、键盘焦点和减少动画。
- 组装与预检测试证明 Desktop 只挂载一个市场插件，普通 Web composition 不挂载 Desktop 市场，冲突在包写入前失败，自我更新、自我停用和自我删除继续阻止，其他 Host 路由与包运行器操作保持上游权限。
- Mac staged artifact 和 packaged smoke 验证替代市场的 Host、Client、Desktop adapter、pnpm 入口、第三方声明、随机端口和退出清理；本轮不修改或发布 Windows 成品。

## 范围外

重写目录服务、允许任意 GitHub 仓库安装、发布者账号、评分评论、CDN、遥测、Electron 权限、Harness 核心设置槽位、Windows 打包和自动升级上游市场不在本设计范围内。
