# 个性化、实时计费与记忆集成设计

[English](2026-08-24-personalization-balance-memory-design.md) | 中文

**日期：** 2026-08-24

**状态：** 已批准实现

**目标：** 面向 Intel macOS 与 Windows x64 的 DeepSeek Harness Desktop 0.3.6

## 目标

Desktop 0.3.6 新增一个全局“个性化”页面，让输入框底部的计费数据真实且能随时间更新，并把 `dsh-missher-memory` 作为可发现的内置插件交付。实现继续遵守 Harness 插件边界：个性化复用规范的全局指令文件，记忆插件仍可独立安装和升级，计费仍是仅面向 DeepSeek 的可选能力。

## 计费数据

统计栏在每个分隔符两侧保留空格，并把会话活动与计费数据分成可读的信息组。存在受支持的 DeepSeek 用量时，计费组显示本轮估算、会话估算、精确账户余额和当前北京时间价格时段。余额传输失败时显示“余额暂不可用”；系统不会伪造零余额，也不会用估算费用从假定初始余额中扣减。

Host 从 DeepSeek 文档规定的 `/user/balance` 响应取得精确余额，并只通过既有的、受能力限制的同源桥接暴露校验后的币种与总额。即使 LLM 插件先启动，桥接也会在 Web Server 服务出现时挂载，并随所属生命周期卸载。

价格估算和时段文案共用同一个北京时间快照。工作日高峰为 09:00–12:00 与 14:00–18:00；工作日其余时间及整个周末均为低谷。客户端使用按分钟对齐的时钟在边界自动刷新文案和估算，不依赖无关的聊天重新渲染。不支持或混合的计费模型继续使用既有的真实降级行为，不宣称已知费用。

## 全局个性化

设置新增一级“个性化”页面，其中包含自定义指令编辑器、回复风格选择器、有限状态文案和仅在发生变更后可用的“保存”操作。页面说明更改会从下一次模型步骤起作用于所有聊天，项目指令仍可补充更具体的上下文。

该功能只编辑规范 `$DSH_HOME/AGENTS.md` 中一个由 Desktop 管理并带标记的区块；已有 agent-instructions 包继续作为唯一的模型可见加载器。标记区块之外的内容逐字节保留。修订令牌防止陈旧覆盖，写入以原子替换完成。Host 拒绝 NUL 字节、超限内容、可写的符号链接目标，以及固定全局指令文件之外的任何路径。平台支持 POSIX 权限时，父目录和文件继续保持仅用户可访问。

回复风格选择器把一条简短而明确的规则编译进同一管理区块，而不是另藏一套提示词。清空自定义指令并选择默认风格时，只移除管理区块，不改变用户手动维护的指令。

## 内置记忆插件

Desktop 依赖 `dsh-missher-memory` 的规范发行包，把它加入应用所有的组合配置，并通过普通插件设置和插件市场界面呈现。独立仓库以 GitHub Release 资产和校验和发布同一版本，并设置 `dsh-plugin` 发现主题，因此配置目录安装的更新版本可以覆盖内置回退副本，而不改变 Desktop 的组合契约。

插件对新绑定项目默认开启采集和召回。已有项目行保留其已保存选择。默认开启不会削弱安全边界：未绑定项目不返回也不记录内容；召回仍限定当前项目和顶层代理；采集只产生待审核候选，不会直接成为已批准记忆；敏感内容会被拒绝；失败不会阻塞模型请求。用户可在插件自己的设置中分别关闭两项行为。

## 组合与升级行为

无需单独使用终端安装即可获得内置插件。插件市场安装仍是事务性的，配置目录内的包在模块解析时优先于内置副本。因此移除通过市场安装的更新版本后，会回退到 Desktop 副本，而不会删除应用所有的组合行。未来 Desktop 更新可以提高回退版本，独立插件则保留自己的发布节奏。

0.3.6 源码在 macOS 与 Windows 间共享。两个原生安装包只能从同一个已验证提交生成。平台打包差异不得分叉功能行为、配置默认值或本地化文案。

## 失败、隐私与恢复

个性化和记忆功能不会向客户端暴露凭据或任意本地文件。个性化保存失败时保留原文件，并显示可重试错误。DeepSeek 余额响应缺失或无效只影响余额文案。记忆数据库失败时聊天请求保持放行，诊断信息留在插件界面中。

回滚可删除应用所有的记忆组合行和包依赖，或移除个性化管理区块，不删除用户手写的全局指令、插件状态、项目数据或 `$DSH_HOME`。原生卸载继续保留用户数据。

## 验证

聚焦测试覆盖 Web Server 延迟注入、余额校验、价格边界时钟跳变、可见分隔符空格、余额不可用文案、管理区块解析与带修订的原子写入、符号链接和大小拒绝、回复风格渲染、新项目记忆默认值、已有项目设置保留，以及 Bundle 组合。

浏览器验收覆盖浅色和深色主题下的个性化页面、未变更/保存/错误状态、窄设置布局、键盘导航，以及价格边界前后的统计栏。插件验收在隔离配置中安装和升级已发布包，并证明应用内置回退仍可加载。

Intel macOS 与 Windows x64 打包冒烟使用隔离的运行目录。每个原生包都必须启动真实 Harness 界面、加载内置记忆插件、保存并重新读取个性化设置、获取或真实降级可选余额、退出后不留下孤儿进程，并在卸载或替换后保留隔离数据。

## 不在范围内

自动批准记忆候选、显式绑定前的跨项目召回、任意文件编辑、账单对账、非 DeepSeek 价格估算、个性化云同步，以及破坏性迁移已有记忆设置，都不属于本次交付。
