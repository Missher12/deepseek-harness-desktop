# DeepSeek Harness Windows 0.3.2 同步设计

[English](2026-08-21-windows-0.3.2-sync-design.md) | 中文

## 目标

使用已经通过验证的 Intel macOS 版所采用的同一份 Desktop 0.3.2 源码发布 Windows x64 Setup。Windows 安装包必须提供共享的 0.3.2 产品体验，同时保留现有的可视安装、启动、剪贴板、进程和用户数据保护。

本次同步必须通过一条仅构建 Windows 的原生构建与发布路径完成，不得重新构建、替换或重命名现有 macOS 产物。

## 源码与版本归属

- 公开默认分支是 Windows 安装包的唯一源码，不把功能复制到平台专用分支。
- `apps/desktop/package.json` 负责提供 Desktop 版本，产物名称从该值派生。
- Windows Setup 及其校验文件通过原生验证后加入现有 `desktop-v0.3.2` Release。
- 后续 Windows 构建沿用同一版本派生机制，因此 Desktop 版本变化时，工作流文件名不会停留在旧版本。

## 构建与发布流程

Windows 工作流只读取一次 Desktop 版本，通过步骤输出传递该值，并将派生出的产物路径用于打包、安装界面冒烟测试、已安装应用冒烟测试、校验文件生成和产物上传。在公开默认分支上运行的 workflow-dispatch 是 Windows 行为的发布依据。

工作流在没有 Release 写入权限的情况下把构建产物上传到 GitHub Actions。运行成功后，发布操作方下载这些确切产物，验证校验值和安装包内容，然后仅把 Windows Setup 及其校验文件上传到 `desktop-v0.3.2`。这项分离机制可以防止 Windows 任务替换 macOS DMG、macOS 校验文件或更新 manifest（元数据清单）。

## Windows 适配范围

- 保留辅助式单用户安装程序，包括欢迎、安装位置、进度／详情、完成、快捷方式、自动启动和卸载行为。
- 在已安装的 Windows 应用中验证共享的 0.3.2 添加菜单、SVG 图标、自适应推理控件、正式品牌和工作台。
- 当共享功能到达操作系统边界时，采用 Windows 原生的终端、路径、进程树、目录选择器和快捷方式行为。
- Windows 不得暴露 macOS 系统更新桥接。
- 保留普通和归档会话 ID 的精确复制、剪贴板默认拒绝权限、启动 URL 校验以及 `~/.dsh` 用户数据。

实现改动仅限发布自动化，以及原生运行所证明的 Windows 兼容性缺陷。不得为了让 Windows 断言通过而改变共享界面或 Mac 行为。

## 失败处理

- 缺少版本化产物、出现重复产物或出现非预期产物时，流程必须在安装前失败。
- 安装程序、启动、剪贴板、工作台或卸载验证失败时，流程停止发布并保留现有公开 Release 产物。
- 校验值不匹配或安装包包含非预期敏感路径时，流程停止上传。
- Release 上传必须使用确切产物名称，不得使用通配符或替换整个 Release 的操作。
- 上传失败时按确切 asset ID 检查；只能删除并重试未完成的 Windows 产物。

## 验证

本地检查覆盖动态版本工作流约定、受影响的 Desktop 测试、格式和密钥引用。Windows 原生验收覆盖可视安装程序、快捷方式、自动启动、应用版本与品牌、Harness 在自有随机回环端口上的启动、添加菜单、推理控件、工作台模式、目录选择器、普通与归档会话剪贴板值、权限拒绝反馈、进程清理、卸载和用户数据保留。

最终安装包需要在 `app.asar` 内外检查 `.env`、凭据和 `.dsh` 路径。工作流不得引用 API Key secret。公开验收要求 GitHub 产物状态为 `uploaded`、字节数精确、API digest 匹配、匿名重新下载并且 SHA-256 匹配。

## 非目标

- 重新构建或修改已经验证的 Intel macOS 0.3.2 安装包。
- 在 Windows 同步任务中发布历史 macOS 版本。
- 增加代码签名、Windows 自动更新或无关界面改动。
- 把 0.3.2 功能回移到长期存在的 Windows 专用源码分支。

## 验收标准

- macOS 与 Windows 公开安装包都报告 Desktop 0.3.2。
- Windows Setup 通过可视辅助页面完成安装与启动，无需 Node.js、pnpm、终端、浏览器或手动端口配置。
- 已安装的 Windows 应用提供共享的 0.3.2 体验，并通过原生安全和生命周期检查。
- Windows Setup 与仅含 LF 换行的校验文件均可公开下载，并且与已验证的工作流产物逐字节相同。
- 现有 macOS Release 产物的 asset ID、大小和 digest 保持不变。
