# Desktop 0.5.4 界面与插件集成设计

[English](2026-09-04-desktop-0.5.4-interface-integrations-design.md) | 中文

**状态：** 用户已于 2026-09-04 批准；实现待完成

**Desktop 基线：** `0da8093092c9a29f5cebdfc094d0b58d97b56219`（`desktop-v0.5.3`）

**目标：** Desktop `0.5.4`，内置 Harness `0.1.2-rc.1`

## 目标

让安装版在正常窗口尺寸下成为一个协调的整体：保留 macOS 标题栏安全区，把轮次刻度固定到左侧，把类似 ChatGPT 的清晰 Workbench 停靠在右侧，让可调用技能/插件出现在 `@` 与 `+` 的首屏，并让真实 BrowserSkill 与 Open Design 集成容易被发现，同时不给冷启动增加额外工作。

## 产品模型

- Desktop 继续只有三类主区域：侧栏、会话与一个右侧 Workbench。不增加第二个侧边聊天或重复浏览器表面。
- `@` 是聚焦发现入口：目标与计划在最前，然后是可调用技能/插件、动态 Cordis 插件、文件与会话。输入查询后搜索全部分组；普通命令继续留在 `/`。
- `+` 保留文件/图片优先、目标/计划其次、可调用技能/插件随后；不再用全部普通 slash 命令淹没首屏。
- BrowserSkill 继续使用已内置的 `@wxg-prc-cpg/browser-skill-dsh-plugin`。`browser-skill` 是真实可执行技能，六个工具继续等到技能被调用后才懒加载。
- Open Design 继续是独立安装的官方应用，并通过官方 `@open-design/dsh-runtime` companion 保存到隔离的 `open-design` DSH profile。Desktop 可以按需显示经过脱敏的安装事实，但不能把它复制进默认 `web` profile、伪造一个技能或暴露文件路径。

## 原生窗口栏

- context-isolated preload bridge 是原生标题栏呈现的持久真源。登录跳转即使丢失 URL 参数，也不能丢失 macOS hidden-inset 安全区。
- macOS 保留原生红黄绿按钮与 38px 可拖动区域。侧栏、会话标题、Workbench 控件与关闭按钮都从该区域下方开始。
- Windows 保持当前原生窗口框架，不增加模拟顶部留白。

## 轮次刻度

独立的左侧刻度规格继续作为权威约定：Workbench 关闭时，默认 1012px 窗口仍能看到刻度；刻度浮在 transcript 文档流之外，只有中心列小于 680px 才隐藏。

## Workbench

- 使用“图标 + 文字”的入口明确表达 Workbench；无障碍名称仍随打开/关闭状态变化。
- 侧栏自动折叠时，1012px 窗口要停靠 300–360px Workbench，并保留 640px 会话下限。小于精确适配阈值时才使用现有覆盖式 drawer。
- 纵向入口保持“审阅、终端、浏览器、文件、插件”。为兼容已保存偏好，内部仍使用 `browserSkill` mode id，但用户看到的名称改为“插件”。
- 插件页同时显示 BrowserSkill 的显式检测与 Open Design companion 的只读状态。BrowserSkill 只有用户点击“检测”才启动进程/扩展探测；Open Design 只有打开插件页时执行一次有界 manifest 读取。

## 数据与接口

- `DesktopApi.presentation` 是 preload 提供的不可变事实，标题栏取值使用封闭枚举。
- `DesktopApi.getIntegrations()` 返回封闭、脱敏的 Open Design 状态：`installed` 或 `missing`、固定 profile 名及可选 companion 版本。不得返回路径、命令、环境值或凭据。
- 输入候选增加目标、计划、技能与插件的明确图标；排序继续由 source 所有并保持确定性。
- 既有“本会话不再询问”审批持久化保持不变并补回归测试，本版本不扩大审批权限。

## 性能边界

任何插件发现都不能在 Desktop 启动期运行 daemon、浏览器、CLI、profile probe 或网络请求。技能目录保留既有会话预热；Open Design 只在打开插件页时检查，BrowserSkill 只在用户明确点击“检测”后探测。

## 验收

1. 登录跳转后，macOS 仍有 `data-dsh-titlebar="hidden-inset"`；侧栏、标题栏或 Workbench 控件均不与原生红黄绿区域相交。
2. 默认窗口在 Workbench 关闭时显示左侧轮次刻度；打开预览不移动 transcript 文字。
3. 1012px、侧栏折叠时，Workbench 是停靠列而非覆盖层；真正窄窗才变为 drawer，空间恢复后保留原宽度偏好。
4. 裸 `@` 在文件/会话之前显示目标/计划与 `browser-skill`。`+` 只显示整理后的“添加、目标/计划、插件”分组；选择 `browser-skill` 插入规范 `/browser-skill` 调用。
5. 插件页可看到 BrowserSkill，并能在不泄露路径的情况下报告本机 Open Design companion 已安装；两者都不在启动期探测。
6. Mac Intel 与 Windows x64 打包 smoke 覆盖平台标题栏差异、100%/150% 几何、左侧刻度、停靠/drawer Workbench、插件发现与完整进程清理。

## 回滚

标题栏 bridge、刻度位置、Workbench 几何、入口排序与集成状态分别提交。回滚任何一项都不得移除 BrowserSkill 包、Open Design profile、用户会话、记忆、进化数据、审批状态或 Desktop 偏好。
