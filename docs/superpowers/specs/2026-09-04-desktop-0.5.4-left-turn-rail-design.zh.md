# Desktop 0.5.4 左侧轮次刻度设计

[English](2026-09-04-desktop-0.5.4-left-turn-rail-design.md) | 中文

**状态：** 用户已于 2026-09-04 批准推荐方向；书面规格待复核

**Desktop 基线：** `0da8093092c9a29f5cebdfc094d0b58d97b56219`（公开 `desktop-v0.5.3`）

**Harness core 基线：** `0.1.2-alpha.5`

**目标 Desktop 版本：** `0.5.4`

## 目标

把轮次导航轨放到会话正文左沟槽，与 transcript（文本记录）正文保持清晰间距，并保留现有完整历史、键盘、预览和避让输入区行为。

## 已确认的问题

已批准的 0.5.3 设计把轮次导航放在左沟槽，但已发布样式表的说明和 `right` 定位都把它锚在右沟槽，预览因此从右边缘朝 transcript 展开。这是实现偏离，不是新的偏好或数据模型缺陷。

现有第一方 `TurnNavigator`、`turnOutline`、`loadThrough` 与当前轮次状态继续作为唯一导航真源。本工作只改变位置与碰撞行为。

## 视觉约定

- 导航轨占据会话起始侧沟槽，在支持的中文和英文布局中就是左沟槽。
- 静止轨道位于 transcript 正文列之外，保持可见的 12–16px 间距。它不得改变消息宽度、缩进或换行。
- 所有刻度共用一个左侧起点并向 transcript 方向延伸。静止、预览、忙碌、未加载、当前和键盘焦点状态保留现有语义。
- 预览作为浮动层向导航轨右侧展开。它不参与文档流，不改变 transcript 几何，并与轨道保持 10–12px 间距。
- 预览宽度仍不超过 300px，显示一行提示词和最多三行回复，并继续使用有界会话区域做垂直 clamp。
- 用户悬停或聚焦刻度时，预览可以短暂覆盖 transcript 内容，但绝不能进入 composer、QueueDock、统计行或右侧 Workbench。
- 零高度 sticky slot 继续保持零高度，因此导航轨和预览不增加 transcript 滚动高度。
- 少于两个轮次时不渲染导航轨。长历史在导航轨内部滚动；除非指针正在控制导航轨，当前刻度始终留在可视区域。
- 当会话宽度触发现有窄窗断点时，导航轨继续隐藏，不挤压正文。

## 交互与无障碍

- 指针移动预览最近刻度，点击导航使用同一固定节距映射。
- 每个轮次继续作为可用键盘聚焦的按钮，并保留现有本地化无障碍名称、`aria-current`、`aria-busy` 和 tooltip 关系。
- 减少动态效果模式关闭导航轨和预览动画，但不改变导航行为。
- 深浅主题使用现有设计 token；任何固定黑色、白色或平台专属颜色都不能成为状态真源。

## 实现边界

- 优先使用 CSS 逻辑定位表示会话起始侧，并说明支持的语言环境中最终呈现为左侧。
- 除非失败测试证明存在位置相关缺陷，否则保持 `TurnNavigator.tsx`、轮次 outline 模型、分页和导航回调不变。
- 不增加第二套导航轨，不导入 `dsh-session-nav`，也不让 Desktop 代码定位生成后的 CSS 模块类名。
- 不为临时预览永久预留整列宽度，也不移动 transcript 给预览让位。
- 本轨道不修改固定右侧 Workbench、BrowserSkill、审批行为、会话分组或 composer 布局。

## 测试与证据

1. 聚焦样式约定测试在导航轨锚定右侧时失败，只有轨道锚定起始侧且预览朝 transcript 展开时才通过。
2. 组件测试继续覆盖完整历史、未加载页导航、当前状态、键盘、长历史滚动和减少动态效果。
3. 100%、150% 与 200% 浏览器布局测试验证导航轨位于首条 transcript 内容左侧、轨道可见，并且打开预览不改变 transcript 尺寸。
4. 短内容、长内容、中英文内容测试验证预览留在测量后的 composer 区域之外，且不与右侧 Workbench 相交。
5. Mac Intel 与 Windows x64 原生证据在各自平台缩放下捕获导航轨、至少两个刻度、一个当前刻度和一个打开的预览。

## 所有权与交付

总指挥独占共享轮次导航实现及跨平台测试。Mac 与 Windows 执行任务只消费同一个共享提交，并各自拥有平台原生视觉验收。两个平台任务都不得单独改写共享导航轨样式。

导航轨改动作为独立提交先于任何启动优化落地。未达到性能门禁的启动实验不得阻断或改写已验收的导航轨修正。

## 验收标准

1. 双平台发布版的导航轨都清楚位于会话正文左侧。
2. 打开或关闭预览不会移动、缩放 transcript 正文或改变其换行。
3. 预览在 100%、150% 与 200% 缩放下都不与 composer 区域重叠。
4. 完整历史导航、加载旧轮次、当前刻度跟随、键盘焦点与减少动态效果不退化。
5. 右侧 Workbench 及其入口保持现有几何和行为。

## 回滚

视觉提交可以独立回滚，不改变轮次数据、会话文件、分页、BrowserSkill 或启动代码。回滚只恢复已发布 0.5.3 的右侧位置。
