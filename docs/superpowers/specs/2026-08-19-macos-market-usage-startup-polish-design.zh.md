# macOS 插件市场、使用统计与启动体验优化设计

[English](2026-08-19-macos-market-usage-startup-polish-design.md) | 中文

**日期：** 2026-08-19

**状态：** 已批准实现

**目标：** Intel macOS 上的 DeepSeek Harness Desktop

## 目标

Intel macOS 应用提供信息密度更高的插件市场，在使用统计数据返回前展示与仪表盘结构一致的占位界面，以使用 DeepSeek 配色的短时工业风入场动画替换通用启动转圈并直接进入真实页面，同时在输入框统计条增加可信的会话费用估算和 DeepSeek 账户余额。跨会话消息协议、插件市场后端行为、使用统计聚合、Electron 安全策略和单原生窗口架构保持不变。

## 范围与边界

本次交付修改四条有边界的路径：已打补丁的 `dshmarket@1.10.1` Client 列表、`@deepseek-ai/dsh-client-ui-settings-usage`、macOS Desktop 启动界面，以及现有输入框统计条和可选的只读 DeepSeek 余额桥。本次不新增 Windows 构建、Windows 验收工作、ARM macOS 打包、新统计数据源、第二个 BrowserWindow、通过网络加载的视觉资源或新的插件市场操作。

仓库原本共用的源组件仍保持可移植，但接近发布形态的验证与交付仅面向 Intel macOS。应用进入真实 UI 后，现有浅色与深色主题 token 继续作为真源。

## 视觉语言

启动界面借鉴深色工业游戏界面的动效语言，但不复制外部图片、字体、文字或品牌资源。接近黑色的底色、DeepSeek 蓝、冷青色、白色字阶、细网格线、切片字层、稀疏技术标签和一次横向扫描替换 Demo 中的黄色强调色。主色板只使用本地 CSS 和现有 Harness 主题 token，不发起网络请求。

DeepSeek 名称保持清晰并与品牌一致。大号描边 `HARNESS` 字样、范围明确的运行时标签和错峰出现的小字建立视觉层级。装饰文字只描述 Desktop 运行时、会话、插件和使用统计等真实本地属性，不显示虚假百分比、编造状态或包含凭据的值。

## 启动顺序

现有原生启动页增加一个 macOS 专用的自包含变体。它立即出现，在约 900 毫秒内组装 DeepSeek 字标和辅助文字，随后在运行时继续就绪期间停留于低动态深色画面。运行时启动与冲突检查保留现有顺序和并行关系；入场动画不会推迟 Harness 进程启动。

Desktop URL 标识 Darwin 界面。Client 插件完全停稳前，自给自足的 `AppRoot` 只为该界面渲染与原生页一致的内核自有停留画面，不再显示通用的 `Loading plugins…` 转圈。它不导入任何插件包，并在启动失败时保留现有逐项快速暴露错误的诊断信息。

Client loader 完全停稳后，`AppRoot` 在启动覆盖层下方挂载真实应用。一个 240–320 毫秒的 DeepSeek 蓝色切屏移除覆盖层，因此接下来显示的是可用页面，而不是骨架、空白画面或第二条加载消息。切屏与真实应用的第一次渲染重叠，不延迟运行时启动或插件激活。减少动态效果模式会跳过组装、扫描和切屏动效，直接从静态品牌画面切换到真实页面。

这项工作改善启动连续性和感知延迟。在没有测量证据前，它不宣称缩短冷启动总时长；更深入的插件图或包拆分改动仍属于独立工作。

## 使用统计加载与刷新

第一次打开使用统计时，页面渲染与最终五项摘要、活动区和两列详情结构一致的骨架。骨架单元不显示任何数字，提供 `aria-busy`，保持最终页面尺寸，并使用轻微的 DeepSeek 蓝色扫光；减少动态效果模式下改为静态占位。可见的 `加载中…` 句子被移除。

Client 只在进程内保存最近一次成功且不可变的使用统计快照。再次进入设置时立即渲染该快照，同时启动一次后台刷新。刷新成功后原子替换快照；刷新失败则保留可见快照，用范围明确的本地化状态标记数据可能陈旧，并提供重试操作；如果首次加载没有快照便失败，则保留现有明确错误与重试状态。不增加浏览器存储、会话内容或新遥测。

## 插件市场 B2 行

发现结果使用单个高密度横向行。左侧会立即绘制固定 42 像素的 DeepSeek 蓝色确定性首字母图块；远程所有者图片只有解码完成后才淡入覆盖，因此请求缓慢或失败都不会留下空白图片框。中间列包含带内联分类标签的插件名称、由所有者、星标和发布日期组成的一行元数据，以及一行描述。右侧为 DeepSeek 主色的紧凑操作和仅图标的溢出菜单；详情、源码和复制包名继续位于溢出菜单内。

该行在内容到达前预留图片与操作区域，截断过长值并避免页面横向溢出。在较窄的设置页宽度下，插件名称、内联分类、主操作和溢出操作仍固定对齐在第一行；过长名称通过省略号让出空间，不再把任一操作挤到标题下方。焦点、无障碍名称、来源警告、弃用状态、安装进度、深色模式和减少动态效果均保留明确覆盖。后端路由、确认、锁定、备份、回滚、自保护和包变更语义不变。

## 会话费用与账户余额

输入框统计条只在整段持久日志的 token 投影包含可计费用量，且配套的持久 `tokenBillingModel` 投影能确定唯一受支持的 DeepSeek V4 路由时，增加“本会话估算 ≈ ¥…”；使用当前官方人民币百万 token 单价：Flash 缓存命中／未命中／输出为 ¥0.02／¥1／¥2，Pro 为 ¥0.025／¥3／¥6。缓存写入按未缓存输入计价。未知模型或混用模型时隐藏费用估算，不展示误导数字。文案和提示必须明确这是估算值。

精确账户余额通过可选的、能力令牌保护的同源 Host 桥读取 DeepSeek 官方 `GET /user/balance` 接口，复用已配置凭据但不把凭据写入日志或应用状态。Host 验证供应商返回值，多币种时优先人民币，成功结果缓存 60 秒，并发请求合并，10 秒超时。Client 仅在成功返回后展示币种和总余额；凭据不可用、非 DeepSeek 地址、供应商错误或无效响应时保持安静，不显示虚假零值，也不在聊天统计条显示错误。

## 失败与无障碍

启动失败仍停留在内核自有界面，并展示准确的失败条目标识和范围明确的错误文字。运行时冲突和原生失败页保留现有恢复操作。使用统计骨架和刷新状态会如实播报忙碌或陈旧状态，不移动键盘焦点。插件市场控件保留包含插件名称的无障碍名称和可见焦点。

所有动画界面均遵守 `prefers-reduced-motion`。状态不只依赖颜色表达，装饰层不进入无障碍树，启动覆盖层退出后真实应用可立即通过键盘访问。

## 验证

组件和源形态测试覆盖 macOS 启动页、Darwin URL 选择、内核停留与退出状态、减少动态效果、使用统计骨架与缓存刷新行为、插件市场 B2 信息层级与溢出控件、官方人民币计价、混用模型隐藏、余额响应验证、能力令牌拒绝、缓存／并发合并和 Client 静默降级。现有启动生命周期、就绪检查、使用统计投影、插件市场行为和跨会话消息测试保持通过。

浏览器验收使用真实的 800 像素 Desktop 窗口，覆盖浅色与深色主题、窄设置宽度、200% 缩放、较长英文值、键盘导航、减少动态效果、启动失败、首次使用统计加载、缓存刷新失败和插件市场操作进度。页面不得出现横向溢出、空白中间帧、重复启动动画或控制台错误。

打包后的 Intel macOS 冒烟测试使用隔离的 `DSH_HOME`，通过原生启动器打开真实应用，截取启动与稳定界面，验证一个 BrowserWindow 和一棵受控 Harness 进程树，并确认应用干净退出。本次交付不构建、修改、发布或宣称任何 Windows 产物。
