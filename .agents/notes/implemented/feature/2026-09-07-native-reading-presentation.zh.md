# Agent Note：内置阅读展示

Status: implemented

[English](2026-09-07-native-reading-presentation.md) | 中文

## 问题

单行思考预览隐藏了长任务原文的结构。把所有终止轮次都折叠会隐藏未成功的工作，隐藏选中文字则会打断阅读。

## 决策

Chat 在现有 Assistant 渲染器中拥有这套展示。中性思考卡片保留一个原始 Text 节点；前缀追加使用 Text.appendData，保留浏览器选区偏移。卡片每 800ms 最多跟随两行实际行高。滚轮、触摸、视口聚焦和选字暂停跟随，恢复必须由读者明确触发。展开改变同一个视口，保留文本和阅读位置。已完成历史、后台文档和减少动态效果模式不自动滚动。历史卡片不持有实时跟随计时器或文档动效监听器。

正文继续使用原生 Markdown 渲染器。流式中新挂载的段落使用短暂透明度过渡，已收到的文本不进入第二条打字队列。原生工具、附件、审批和错误渲染器保留各自所有权与源顺序。

Compact 仅在 Turn 成功完成、最终答案边界合格且历史完整时折叠。取消、失败、阻塞、中断、输出上限和未知结束原因保留过程证据可见。实时文本选区把隐藏延迟到选区清除；拥有焦点的后代让其过程保持展开。稳定且可搜索的包装器保留浏览器查找和已挂载渲染器状态。

阅读体验参考 [dsh-better-display](https://github.com/aa2246740/dsh-better-display)。该实现属于原生 Chat，不增加外部加载器、模型指令或可执行的回答卡片。

## 备选方案

第二套会话投影会重复原生工具和 Markdown 行为，并让 Desktop 耦合到另一种插件加载器。每次增量替换完整思考 Text 值会破坏选区偏移。模拟打字队列会延迟模型已交付的文本。

## 影响

显示偏好和本地阅读手势位于 Session 日志之外。单元测试覆盖终止结果、选区、跟随、减少动态效果和释放。组装浏览器场景通过真实输入框驱动受控模型流，并记录最终 Markdown 输出；平台打包与原生验收仍是独立要求。

浏览器回放把时区固定为录制语料的时区，并检查思考卡片的无障碍展开按钮及自动换行的流式文本。取消后的 Turn 只有过程可见这一种状态，因此移除过时的单独展开态快照。原生提供方夹具区分一次精确阅读请求与其一次有界自动标题请求；无关或重复请求仍会触发拦截。适配器测试经过真实标题服务与 PiAI 转换，HTTP 用例覆盖标题在阅读流之前、期间或之后到达的情况。
