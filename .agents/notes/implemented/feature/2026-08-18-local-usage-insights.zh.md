# Agent Note: 设置中的本地全历史使用统计

Status: implemented

[English](2026-08-18-local-usage-insights.md) | 中文

## 问题

桌面用户可以查看单个对话，却无法回答累计 Token、峰值用量、活跃天数、连续天数或最常 使用哪些 Harness 功能等全历史问题。如果在浏览器中计算，就需要通过 Remote 边界发送 完整 Session 日志，每次打开设置都重复一次无界折叠，还会把展示代码不需要的提示词、 工具参数和结果暴露给它。

历史工具调用也没有记录稳定的 Loader 插件归属。把这样的排行称为“最常用插件”，会 夸大持久化日志能够证明的事实。

## 决策

`@deepseek-ai/dsh-usage-insights` 拥有 Host 侧、感知修订号的派生索引。它枚举所有 持久化 Session，包括归档和子 Agent，并且只折叠提供方用量、已完成轮次边界、真人 活动、显式 skill 元数据、工具标识、模型路由与推理强度选择。分叉 Session 通过 `seedLength` 排除继承的前缀。Token 总量使用非缓存输入、输出、缓存读取和缓存写入之 和；推理 Token 保持包含在输出中。会话时长取已完成轮次的时长之和，不计算轮次间的 空闲墙钟时间。

`usage_insights` 存储域为每个 Session 保存一条可重建记录。记录只包含稳定标识、日期 分桶、计数和来源修订号，绝不保存提示词、回复、工具参数、工具结果、标题、工作目录、 附件或凭据。修订号一致时复用；变化或无效的记录以有界并发重建。单个 Session 出错时 返回带省略数量的部分快照，不让整个设置界面失败。实时 Session 事件会把对应记录标为 脏，避免在活跃写入期间把旧修订号持久化。

`usageInsights.snapshot()` 是唯一 Remote 方法。它返回五项顶部指标、固定 371 天活动 序列、活动洞察和五行功能排行。若今天没有真人消息，当前连续天数允许终点停在昨天。 每日边界使用 Host 机器当前时区。无效或缺失的提供方 Token 字段保持缺失，不做估算。

`@deepseek-ai/dsh-client-ui-settings-usage` 在模型与插件之间注册本地化设置分区，展示五项 指标，并让每日、每周与累计悬停口径共用同一套 53×7 颗粒。每日保持日历热力图；每周 与累计在完整灰色底盘上按周日对齐、从下向上填充，并使用按口径区分日期文案的圆角可见 浮层。早于可见范围的 Token 会作为累计堆叠基线，使最后一列与顶部全历史值一致。其后 展示活动洞察，以及如实标为“最常用的功能”的排行，并区分 skill 和工具。加载、空结果、部分结果与重试 状态都留在本分区内；不可用值显示破折号， 现有紧凑设置宽度保持不变。

## 验证

纯折叠测试覆盖 Token 替换、缓存分桶、推理不重复相加、分叉前缀、轮次时长、本地日期 活动、显式 skill、原生工具与 Code Mode 调度。聚合测试覆盖 371 天序列、强度等级、 连续天数规则、功能、模型、推理强度和缓存命中率。Loader 测试挂载真实 JSONL 持久化 和 JSON 存储插件，验证首次构建复用、修订号失效、删除、部分失败与实时脏标记。客户端 测试覆盖图表投影、本地化、状态处理、标签键盘行为与窄宽度无溢出。Bundle 和 Remote 测试证明新的 Host 与 Client 条目可以通过普通 Web 树组合。

## 考虑过的替代方案

**在浏览器中折叠完整日志。** 否决，因为它扩大 Remote 数据面、重复昂贵工作，并把 展示代码不需要的内容交给它。

**保存一份全局汇总。** 否决，因为任意 Session 修订都会让整个缓存失效，也难以处理 删除或部分修复。每个 Session 一行可以精确替换和有界增量重建。

**按工具名称给插件排行。** 否决，因为工具名称不是持久化插件身份。产品把证据标为 功能，不猜测归属。

**估算缺失的提供方用量。** 否决，因为依赖 Tokenizer 的估算会把不兼容的语义混入 提供方计量，让总数显得比记录本身更权威。

## 后果

设置页无需模型调用或新增 Electron IPC，就能汇总全部本地历史；后续打开会复用 Session 修订号。第一次冷读取仍可能检查每个持久化 Session，损坏或暂时无法读取的记录会让 快照明确标为部分数据。Host 更换时区后，午夜附近的事件可能在记录重建时换到另一日。 实时更新会在下一次打开分区或重试时出现，而不是持续推送成实时仪表盘。
