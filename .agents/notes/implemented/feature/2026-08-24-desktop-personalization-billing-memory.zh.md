# Agent Note: Desktop 个性化、实时计费事实与审核式记忆

Status: implemented

[English](2026-08-24-desktop-personalization-billing-memory.md) | 中文

## Problem

Desktop 用户没有由应用管理的位置来定义适用于所有聊天的规则。会话底部根据过期的 provider 快照估算费用，既不能显示官方账户余额，也不能在北京时间跨越计价边界时更新 DeepSeek 峰谷标签。超长项目还需要有界连续记忆，但仅把记忆依赖打进应用不会出现在插件市场，因为市场通常只从可变 profile 清单推导已安装列表。

这些缺口不能靠覆盖任意用户文件或静默安装 profile 插件来解决；两种方式都会模糊所有权、增加更新脆弱性，并可能把收集到的文本误当成已批准记忆。

## Decision

一级 `personalization` 设置页只读写固定 `$DSH_HOME/AGENTS.md` 文件中带标记、由 Desktop 管理的区块。浏览器只提交指令、回复风格和预期版本，绝不提交路径。Host 会拒绝畸形文件、符号链接目标、保留标记、NUL、过期版本和超过 48 KiB 的内容；区块外每个字节都会保留，并以原子替换和仅所有者权限落盘。已有 agent-instructions loader 从下一次请求起使用结果，项目内 `AGENTS.md` 仍是范围更窄的权威规则。

DeepSeek 价格仍是根据已结算 token 用量计算的本地估算，但费率判定会按当前北京时间重新计算，底部每分钟刷新一次。DeepSeek 直连 adapter 通过与模型请求相同的凭据和 base URL 边界调用官方余额接口。精确余额与分时估价开关彼此独立：关闭估算只隐藏估算费用和峰谷文字，仍保留 provider 返回的余额；余额请求失败会明确显示不可用，绝不会冒充为零。

Desktop 把已审核发布的 `dsh-missher-memory@0.1.1` 归档固定为应用依赖，并通过不可变 Desktop 组合插入。新批准绑定的项目默认开启候选收集与有界召回。未绑定项目完全惰性，收集只产生待审核候选而不是可搜索记忆，外部 TencentDB 兼容来源始终只读。

`dshmarket@1.10.1` 增加 Desktop 范围的 `builtins` 配置。内置项只为展示合并进 registry 和 installed 响应，不修改可变 profile 清单。它们通过受保护名称集合返回，不能进入分组和批量更新，并在切换、更新、残留修复或卸载的包操作之前被拒绝。运行时 loader 仍让同名 profile 本地依赖优先，从而保留日后独立升级路径。

## Security and ownership

个性化只拥有一个定界区块，不拥有整个全局指令文档。余额传输始终位于 Host 侧，凭据不会暴露。记忆仅因打开设置页不会创建 `state.db`，不会搜索未绑定项目，也不会自动批准收集内容。插件市场只是这个内置项的展示与控制平面，不成为应用依赖的所有者。

## Alternatives considered

**由浏览器覆盖完整全局 `AGENTS.md`。** 拒绝，因为这可能覆盖手工维护的指令，也会让浏览器输入选择或重定向敏感文件路径。

**在下一次模型请求之前持续显示缓存费率标签。** 拒绝，因为跨过工作日计价边界后，即使用量事实没有变化，底部也会显示错误信息。

**显示推导余额或用户填写余额。** 拒绝，因为只有官方 provider 接口才是账户事实；请求失败必须保持不可用，不能发明数字。

**把记忆包静默加入用户 profile。** 拒绝，因为应用所有权会污染用户配置，卸载语义会含糊，而且失败的 profile 操作可能阻止启动。

**把记忆插件硬编码进公共社区快照。** 拒绝，因为精选 registry 有独立的仓库年龄和历史门槛。Desktop 因此展示带明确归属的内置项，而不假装它已经通过社区目录的独立准入。

**自动批准收集记忆。** 拒绝，因为工具输出、短期错误和注入文本未经审核不能成为持久可信上下文。

## Consequences

Desktop 0.3.6 在两个支持平台上获得全局规则、真实的实时时计费事实，以及默认开启但受审核门控的超长项目记忆路径。内置记忆卡会在插件市场中显示并受保护，不污染 profile；日后同名 profile 本地包仍可覆盖兜底版本。

在社区 registry 能正常列出插件之前，应用需要负责一个外部发布归档和一处有界市场补丁的兼容性。余额可用性仍取决于已配置的 DeepSeek 官方凭据与端点。费用明确标为估算，单独标注的余额才是 provider 事实。

## Verification

Host 测试覆盖个性化解析、字节保留、版本、路径安全、权限与原子写入；Client 测试覆盖稳定加载布局、编辑、风格选择、字节限制与保存失败。计费测试覆盖官方价格、当前北京时间峰谷边界、分钟刷新、余额传输与失败标签。记忆发布包在 macOS Intel、macOS Apple Silicon、Windows x64 和 Linux x64 上运行包检查与原生生命周期 smoke。Desktop 成品 smoke 会写入并重载全局个性化，验证只打开记忆设置时零写入，在市场中看到受保护内置项，并证明受保护操作会被拒绝，而普通 fixture 仍能卸载。
