# Agent Note：覆盖可选客户端服务和待完成操作

Status: implemented

[English](2026-09-22-client-lifecycle-cases.md) | 中文

## Problem

客户端测试遗漏了可选侧栏缺席时的原生文件打开、过期更新命令结果、重复关闭失败提示、非 Error 的宿主拒绝及部分本地模型预设结果。预设拒绝测试在查询结束前就编辑行，因此实际观察的是过期行拒绝，而非用例命名的拒绝。Inspector Console 测试在 ingest 通信暂停时等待 Client 请求，尚未执行恢复通信操作就陷入等待。

## Decision

所属组件和插件测试覆盖侧栏与原生打开及原生拒绝；旧更新命令结束后仍保留较新的推送状态；释放后不再执行工作；并验证模型预设准入、拒绝、已有完整值和相邻行不变。Inspector 测试保留一次获得 Client 确认的往返，与恢复通信同时执行，随后才产生 Console 事件。

## Alternatives considered

**放宽覆盖率或延长超时。** 不采用，因为缺失的观察和暂停通信后的等待都是确定的测试缺口。

**直接调用私有实现回调。** 不采用，因为现有注入插件 API 和已渲染输入事件可以验证产品消费者实际可用的行为。

## Consequences

测试现有生产行为，不增加运行时分支或扩大覆盖率豁免。延迟操作在清理时释放并等待结束，Inspector 测试继续验证两个隔离的 Console 会话和远程对象所有权。
