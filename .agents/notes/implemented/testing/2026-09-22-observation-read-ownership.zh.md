# Agent Note：在持久化读取期间验证观察数据所有权

Status: implemented

[English](2026-09-22-observation-read-ownership.md) | 中文

## Problem

三个冷观察测试假定额外的事件克隆循环会在 800 个事件后让出执行。持久化读取现已声明事件值为独占或共享且已冻结，恢复过程根据[只读迁移准备](../architecture/2026-09-05-read-only-session-migration-preparation.zh.md)直接接收这些值，无需第二次克隆。测试和查询 README 仍保留旧的克隆循环假设。

## Decision

观察测试验证调用方拥有完整的外层数组，同时事件值保留持久化结果中的对象身份。取消和实时所有者接管发生在显式暂停的持久化读取期间；每个测试都会先释放并等待该读取结束，再释放 Context。查询 README 描述当前的数据所有权和取消行为。

## Alternatives considered

**恢复冗余克隆以满足旧测试。** 不采用，因为持久化结果已提供直接接收所需的所有权，额外遍历会增加每次冷读取的工作量。

**删除取消和接管的测试覆盖。** 不采用，因为在准备或缓存持久化 Session 前仍须保证这两种行为。

## Consequences

测试覆盖完整读取、取消和实时所有者优先，不再假定固定事件数量必然触发事件循环让出。产品运行时行为保持不变。
