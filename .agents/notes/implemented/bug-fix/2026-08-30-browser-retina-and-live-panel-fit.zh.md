# Agent Note: 浏览器 Retina 恢复与实时侧栏适配

Status: implemented

[English](2026-08-30-browser-retina-and-live-panel-fit.md) | 中文

## 问题

在已安装的 macOS 成品中，页面导航和辅助功能树已就绪后，官方
`browser_snapshot` 仍可能返回 `INTERNAL`。可选 PNG 流程假设所有 CDP
版本都返回 backing-store 尺寸，但 Retina 渲染器也可能返回准确的 CSS clip
尺寸；可选图片失败还会丢弃已经有效的语义 ref。打包版调试器还在 DOM 之前
启用 Overlay；真实 Electron 会拒绝这个顺序，而测试替身没有拒绝。审批请求
超时后，原生弹窗也会残留在屏幕上。此外，浏览器交给 Agent 后
不再跟随工具侧栏调宽，窄栏会裁切桌面型页面，发言刻度也可能覆盖较高的输入框。
切换到另一个 Harness 会话后，旧会话还会继续占用 Electron 的官方控制身份，导致
新会话即使在旧浏览器停止后也会立即返回 `UNAUTHORIZED`。

## 决策

只接受两种确定性的 CDP 视口尺寸约定：物理 backing-store 像素或 CSS clip
像素。PNG 保持可选；有界截图、编码或渲染器失败时保留已验证的语义快照。
原生日志只记录封闭阶段码和错误码。DOM 必须先于 Overlay 启用，并在自有调试器
清理时一并关闭。Electron 原生审批框绑定准确请求的 AbortSignal，因此请求超时、
取消、窗口隐藏或关闭时也会自动关闭弹窗。

新增只允许可信调用的布局 IPC，在人工或 Agent 持有期间调整同一个既有浏览器
的大小和 zoom。它不能创建、显示、导航或转移视图。页面缩放跟随实时侧栏宽度。
发言刻度改用实测会话视口与输入框几何，不再使用整个窗口高度。
严格会话标题挂载时会发送一个无参数、只可撤销的信号。Electron 只接受可信主 frame，
清除 Give 意图、等待旧会话清理并释放旧的官方绑定。Renderer 不能指定或认领新会话；
只有 owned child 的正式请求可以认领。

## 考虑过的替代方案

**PNG 截图尺寸不同时让整个 snapshot 失败。** 这会保留不必要的严格图片约束，却
丢弃独立验证过的语义 ref。图片只是展示数据，因此只降级图片附件。

**每次调宽后新建一个窄版 Agent 浏览器。** 这会丢失登录状态，并违反准确视图所有权。
只调整布局可以保持身份与控制权不变。

## 后果

只有视觉附件不可用时，官方 BrowserControl 仍可返回可操作 ref；未来失败也能
在不记录页面数据的前提下定位阶段。已安装的 Intel macOS 成品完成了真实官方
`browser_navigate https://example.com/` 后接 `browser_snapshot` 的验收，并在
批准原生弹窗后返回了 8 个语义 ref。同一个受控浏览器会持续跟随分隔线，不会出现
第二个窗口或控制权变化。窄栏会用较小视觉比例换取完整布局，侧栏加宽后自动恢复
到 100% zoom。
切换会话不会再继承上一会话的控制身份；任何试图携带 session 值的畸形 Renderer
调用都会被拒绝。
