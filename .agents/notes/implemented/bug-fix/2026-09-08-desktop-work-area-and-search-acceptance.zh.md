# Agent Note: Desktop 窗口适配当前工作区

Status: implemented

[English](2026-09-08-desktop-work-area-and-search-acceptance.md) | 中文

## Problem

首启与无效状态的默认窗口尺寸会超过较小的桌面工作区，固定最小尺寸也会在高缩放下再次撑大已经适配的窗口。测试使用宽视口时，会掩盖首启操作不可达的问题。Windows Search 截图还可能在查询或搜索结果尚未就绪时，匹配桌面其他位置的应用窗口而假通过。

## Decision

Desktop 按主显示器工作区解析默认尺寸，并将构造器最小尺寸限制在解析结果内。恢复保存的尺寸时，选择可见相交面积最大的合格显示器，并将窗口整体移入该工作区。状态格式不变；文件损坏或缺失均采用同一适配后的回退值。没有可用显示器时，紧急尺寸仍为 1180 乘 760。

成品验收先记录原生窗口与工作区尺寸，并验证首启“继续”操作，再设置任何测试视口。Windows 150% 阅读界面先记录实际几何和轨道的自适应显隐，再单独进行宽视口交互测试。Windows Shell 采样器使用物理坐标比较 DWM 可见窗口边界与工作区、虚拟屏幕范围；GetWindowRect 包含不可见调整边框，仅用于诊断。临时线程 DPI 上下文会恢复。

Search 验收只读取前台无障碍根，要求所属进程为 Shell 搜索进程且查询完整，并等待根内唯一、可见、启用且可操作的应用结果。返回前再次核对查询和前台窗口。后台应用标题、部分查询、缺失或多义结果以及变化的前台均不能满足最终观察条件。Shell 截图作为 CI 诊断材料保留，不用作公开宣传图。

## Alternatives considered

**在截图脚本中调整窗口大小。** 这会掩盖产品初始尺寸缺陷，无法证明用户能够触达首启操作。

**延长等待或保留全桌面名称匹配。** 两者均无法证明 Search 已接受完整查询并产生目标结果。

**选择第一个相交显示器。** 与主屏的一小段重叠可能将主要位于副屏的窗口移到错误屏幕；选择最大合格相交面积可以保持其位置归属。

## Consequences

较小工作区可以使用低于常规 900 乘 620 下限的尺寸。部分越界的保存窗口会在恢复时向内移动。窗口专项测试覆盖小工作区、正常工作区、损坏或缺失状态以及副屏位置。Windows PowerShell 回归用完整和无效观察调用实际最终 Search 判定函数。专属 Mac 与 Windows 任务负责复核最终源码版本的新原生流程；单元和接线检查不代表原生验收。Electron 强制缩放不代表完整系统 DPI 覆盖。
