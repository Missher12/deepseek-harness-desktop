# Agent Note: 桌面对话加载连续性

Status: implemented

[English](2026-09-08-desktop-conversation-loading-continuity.md) | 中文

## 问题

切换会话时，统计数据加载可能导致整行统计消失。供参考的目录刷新期间，已选模型可能仍显示旧值；调用拒绝则可能令选择器持续停用。桌面输入框描边还使用了过强的文字颜色 token。

## 决策

选中的会话在输入状态到达前仍保留 composer dock。当前会话数据尚不存在时，统计保留一行本地化占位文字，绝不沿用另一会话的总计。composer 等待最终布局时，只有 dock 保持可见。

模型目录独立于目录就绪状态发布持久化的会话选择，刷新期间保留可用的标签和分组。选择操作的进行中／错误状态具有独立所有者，目录通知不能清除它。调用拒绝会结束当前操作，generation 和作用域检查排除过期或已销毁的结果。新选提供方在可路由性确定之前不阻塞输入。

桌面输入框静止状态描边使用主题的 `border-l4` token。显式细线与独立焦点轮廓保持布局，并让输入框在两种主题下均可辨认。

冷观察恢复在有界的事件克隆批次之间让出执行。接受新挂载的实时所有者前先检查取消，准备过程只接收完整且独立的数组。按 revision 缓存与不可变观察保留原有所有权；查询包 README 维护缓存契约。

## 考虑过的替代方案

**沿用上一会话显示的统计。** 这能避免空行，却会把另一会话的用量和耗时归到当前会话。占位文字无需虚构数据即可保持布局。

**把选择超时当成成功，或直接解锁并盲目重试。** Host 仍可能提交原选择。客户端展示实际失败并保留操作所有权，不引入相互竞争的写入。

**删除输入框描边。** 这会重现白底输入框难以辨认的问题；语义边框提供更浅的静止轮廓。

**删除历史克隆。** 共享持久化层拥有的事件会削弱观察隔离。分批保留独立快照，同时允许待处理的 Host 工作继续执行。

## 结果

会话切换保留底部统计，目录刷新期间已接受的模型变化可见，调用失败可重试。这些客户端改动不会让始终未结束的 Host 操作成功，也不能替代原生平台验收。归属组件与插件的回归覆盖会话数据源替换、迟到更新、输入加载、刷新期间的选择、重试、被替代的拒绝与作用域销毁。

历史分批降低连续阻塞，但不承诺缩短总恢复时间。解码和准备仍同步执行。观察测试覆盖克隆期间取消、实时所有者接替与最终冻结切面。
