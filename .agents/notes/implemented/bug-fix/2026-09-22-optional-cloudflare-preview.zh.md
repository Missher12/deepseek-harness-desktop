# Agent Note: 在没有 Cloudflare 凭据时构建预览

Status: implemented

[English](2026-09-22-optional-cloudflare-preview.md) | 中文

## 问题

没有 Cloudflare 凭据的仓库能够构建 PR（Pull Request）预览，却会在部署时失败。这会掩盖已经通过的构建验证，并让人误以为尚未配置的托管预览已经存在。

## 决策

[预览工作流](../../../../.github/workflows/build-preview-cloudflare.yml)始终使用固定依赖安装并构建工作区和预览。部署及 Access 凭据均未配置时，它记录未配置部署，并跳过上传、远程验证和 URL 评论。四项凭据全部配置后，执行现有的部署和受保护图片检查。只配置部分凭据时明确失败，且不打印凭据值。

## 考虑过的替代方案

**跳过整个任务。** 这会让没有预览服务的仓库失去有用的构建验证。

**忽略部署错误。** 这会隐藏无效凭据和已明确配置的部署所发生的失败。

## 影响

构建通过不代表预览已经部署。已配置的部署保留原有失败检查。测试使用未配置、完整配置和部分配置的合成凭据执行配置判断，并验证构建步骤始终运行。
