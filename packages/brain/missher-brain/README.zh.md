# dsh-missher-brain

[English](README.md) | 中文

DeepSeek Harness 的本地“外置大脑”中心。它校验并注册相互独立的事实记忆与流程学习 Provider，让后续仲裁器能为每个符合条件的顶层轮次选择一批有界上下文。Provider 继续拥有自己的数据库和副作用；中心不拥有任何用户记忆。

## Provider 约定

- 每个存活 Provider 都有非空唯一 `id`、协议版本 `1`，以及 1 至 6,000 的整数 byte 预算。
- `prepare()` 返回不透明候选项以及单次使用的 `accept()`、`cancel()` 操作。准备候选项不会把它们标为已使用，也不会改变 Provider 状态。
- 注册顺序稳定，并返回精确注册的资源释放函数。旧资源释放函数不能移除使用相同 ID 的后继项。

## 模型体验

### 外置大脑候选项

#### 模型看到的内容

单独使用注册表时什么也看不到。Brain Hub 注入器是唯一能把已选择贡献渲染进符合条件模型步骤的组件。

#### Token 影响

在注入器选择并渲染 Provider 贡献前为零 token；Provider 与中心预算会限制后续上下文。

#### KV Cache 影响

注册表不会触碰请求前缀。后续符合条件的召回只改变该轮外置大脑上下文，可能降低受影响前缀的缓存复用。

## 已知限制与暂缓事项

- 协议版本 `1` 只支持本地纯文本贡献。二进制知识、远程 Provider 发现和跨设备同步不属于本包范围。
